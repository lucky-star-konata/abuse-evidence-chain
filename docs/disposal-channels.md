# 处置渠道

按对象选择渠道，不要群发。提交前核对官方入口是否变更。

## 国内

| 渠道 | 适用 | 入口 |
| --- | --- | --- |
| 国家反诈中心 | 电信网络诈骗、涉诈 App、涉诈网址 | 96110 专线；国家反诈中心 App |
| 网络违法犯罪举报网站 | 涉网违法犯罪线索 | cyberpolice.cn（公安部） |
| 12321 举报中心 | 垃圾信息、诈骗短信/电话、不良 App | 12321.cn |
| 12377 举报中心 | 违法和不良信息 | 12377.cn（中央网信办） |
| CNCERT/CC | 网络安全事件、恶意代码 | cert.org.cn |

报案材料建议包含：案件概述、时间线、证据清单（含哈希）、涉案金额、受害人信息（脱敏）、请求事项。

## 国际与平台

| 对象 | 适用 | 查找方式 |
| --- | --- | --- |
| 域名注册商 | 域名被用于诈骗/仿冒 | 通过 RDAP 查询注册商与 abuse 邮箱 |
| 托管商 / 云厂商 | 站点内容违法 | 通过 IP 的 RDAP/WHOIS 找 abuse 联系人 |
| CDN / 防护厂商 | 站点经其加速 | 厂商 abuse 页面提交通道 |
| Google Safe Browsing | 钓鱼、恶意软件页面 | safebrowsing.google.com 举报入口 |
| Microsoft | 钓鱼、恶意站点 | Microsoft 安全举报入口 |
| APWG | 钓鱼站点 | apwg.org 举报入口 |
| 应用商店 | 恶意 App | App Store / Google Play 举报流程 |
| 社交平台 | 引流账号、群组 | 平台内举报 + 专门执法通道（如有） |

## 举报材料结构

1. **一句话结论**：什么站点、什么行为、请求什么动作
2. **事实**：URL、上线时间、页面内容、下载行为、收款方式
3. **证据**：文件清单 + SHA-256 + 采集时间
4. **影响**：受害人数量级、涉案金额（有依据才写）
5. **请求**：暂停解析 / 下架 / 封禁账号 / 立案
6. **联系方式**：提交人身份与回执邮箱

## 注意事项

- 先固定证据再举报，顺序反了容易丢失页面
- 同一材料不要同时投给互相冲突的渠道
- 保留受理编号、提交时间、回执截图
- 不虚构受害人、金额和团伙关系
- 跨境案件走司法协作或国际组织渠道，不自行处置
